<h1>Series and Pattern Programs in C</h1>

<p>This repository contains a collection of C programs focused on generating numeric series and printing various patterns. These files serve as a useful reference for beginners learning the fundamentals of loops, conditions, and sequences in C programming.</p>

<h2>📁 Folder Structure</h2>
<ul>
  <li><strong>Fibonacci_series.c</strong> – Generates the Fibonacci sequence.</li>
  <li><strong>Lucas_series.c</strong> – Generates the Lucas sequence.</li>
  <li><strong>pattern1.c</strong> to <strong>pattern27.c</strong> – Each file demonstrates a different pattern using loops (nested or simple). Patterns may include pyramids, triangles, number alignments, stars, and other creative designs.</li>
</ul>

<h2>🧠 Concepts Covered</h2>
<ul>
  <li>Looping constructs (<code>for</code>, <code>while</code>)</li>
  <li>Nested loops</li>
  <li>Conditional statements (<code>if</code>, <code>else</code>)</li>
  <li>Function use (in some programs)</li>
  <li>Series generation logic</li>
</ul>

<h2>🚀 Getting Started</h2>
<p>To compile and run any of these programs:</p>
<ol>
  <li>Clone the repository:
    <pre><code>git clone https://github.com/yourusername/series-and-patterns.git
cd series-and-patterns</code></pre>
  </li>
  <li>Compile a specific program:
    <pre><code>gcc pattern1.c -o pattern1
./pattern1</code></pre>
  </li>
</ol>
<p><strong>Note:</strong> Replace <code>pattern1.c</code> with the desired file.</p>
